# GameConsciente

Site educativo e psicológico sobre a influência dos jogos no consumo e no bem-estar de adolescentes.

- Conteúdo sobre consumo, microtransações, loot boxes e efeitos colaterais
- Quiz estilo Kahoot
- Programinhas educativos (calculadora de gastos, tempo de tela, verdadeiro ou falso, autoavaliação, simulador de loot box)
- Perguntas de reflexão
- Chat com assistente educativo

Acesse: https://vitoo-ti.github.io/game-consciente/
